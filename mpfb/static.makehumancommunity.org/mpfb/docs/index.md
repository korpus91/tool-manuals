# MPFB Docs

This is the documentation for MPFB. Note that there is also important information in the FAQ section.

## Overview

- Getting started: Information on how to install MPFB, and how to perform some basic operations.

- Assets: Information on the MPFB asset system, including how to create assets.

- Material types: An overview of the different types of materials MPFB offers

## Basic operation

- Working with characters: Information on how to create, save and load characters

- Randomizing characters: How to generate random characters, one at a time or in batches

- Rigging, posing and animating: Information about how to rig, pose and animate character

- Lip sync: How to set up lip sync animation using facial shape keys and the Lip Sync addon

- Exporting characters: Things to take into account when exporting characters

## Integrating with MakeHuman

- Import paths for MakeHuman: An overview of the different ways to import a character from MakeHuman

- Importing via MHM: Information on how to use the recommended import path

- Importing via Socket: Information on how to use the previously recommended import path

## Other specific tutorials

- Rigging Mesh Assets: describes how to create a sub-rig for a ponytail hair asset.
