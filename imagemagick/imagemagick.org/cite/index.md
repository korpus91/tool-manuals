Learn how to cite ImageMagick in your academic work, software documentation, or publications. Choose from the standard citation formats below:

##### APA Style
 Standard

Best for academic papers in social sciences, education, and psychology.

```
ImageMagick Studio LLC. (2024). ImageMagick. Retrieved from https://imagemagick.org
```

##### Vancouver Style
 Medical & Scientific

Frequently used in biomedical and life sciences literature.

```
1. ImageMagick Studio LLC. ImageMagick [Internet]. 2024. Available from: https://imagemagick.org
```

##### Harvard Style
 Author-Date

Widely used across humanities, science, and business disciplines.

```
ImageMagick Studio LLC, 1999. ImageMagick, Available at: https://imagemagick.org.
```

##### BibTeX Format
 LaTeX / Bibliography

For reference managers and LaTeX document preparation systems.

```
@software{imagemagick,
  author = {{ImageMagick Studio LLC}},
  title = {ImageMagick},
  url = {https://imagemagick.org},
  version = {7.1.2},
  date = {2026-10-20},
}
```
