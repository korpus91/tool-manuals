# Boolean node

The Boolean node generates a 3D signed distance function for the combination (union, intersection or difference) of its inputs. If the input shapes are associated to color indexes, the boolean node applies them to the output.

## Inputs

The Boolean node accepts two or more inputs in 3D signed distance function format.

This node is variadic, and more shapes can be added.

## Outputs

The Boolean node generates a signed distance function of the combination of its inputs.

## Parameters

The Boolean node accepts the operator it applies (union, intersection or difference) as parameter.
