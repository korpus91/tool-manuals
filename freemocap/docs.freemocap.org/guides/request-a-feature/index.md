# Request a feature

New ideas and feature requests from the community are welcome. To propose a new feature or enhancement, please open a new issue with the following details:

- A clear and concise description of the feature

- The problem you're trying to solve or the goal you want to achieve

- If possible, provide examples or mockups to illustrate the desired capability or feature

- Any alternatives or workarounds you've considered, if applicable

The issue template also asks what the use case is, for example whether it helps with scientific data collection or with animating characters from the data.

Please be patient. Not every requested feature can be implemented, but each request gets considered and prioritized based on the needs of the project and the community. For what the team is actively working on, see the roadmap.
