# Cite FreeMoCap

You can cite two things: the software itself, and the validation study behind accuracy, validity, and limits.

## Citing the software​

```

@software{freemocap,

  author       = {Matthis, Jonathan Samir and

                   Queen, Philip and

                   Cherian, Aaron and

                   Wirth, Trent and

                   Idehen, Endurance},

  title        = {FreeMoCap},

  doi          = {10.5281/zenodo.7233713},

  url          = {https://github.com/freemocap/freemocap}

}

```

Or in prose: Matthis, J. S., Queen, P., Cherian, A., Wirth, T., & Idehen, E. FreeMoCap. https://doi.org/10.5281/zenodo.7233713

This DOI always points to the latest release archived on Zenodo. To cite the exact version you used, add its version number (shown in the app under Help > About FreeMoCap). Each archived version also has its own DOI on its Zenodo page.

## Citing the validation study​

```

@phdthesis{cherian2026freemocap,

  author = {Cherian, Aaron},

  title  = {Open-Source Development and Validation of a Low-Cost Markerless System for Quantitative Motion Analysis},

  school = {Northeastern University, Department of Bioengineering},

  year   = {2026}

}

```

Citation link pending publication in Northeastern's institutional repository. If your work depends on both, cite the software alongside it.
