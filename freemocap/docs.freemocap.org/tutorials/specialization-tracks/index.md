# Specialization tracks

Tutorials teach you to use FreeMoCap. Specialization tracks go further. They cover the different domains FreeMoCap's output feeds into, once recording and processing feel familiar.

There are three tracks, matching three different reasons someone reaches for motion capture data in the first place.

## Technology​

This track covers how FreeMoCap's own software works. SkellyCam handles camera sync, SkellyTracker handles pose estimation, SkellyForge handles post-processing, SkellyBlender handles the Blender integration, and the core app runs them all together. This track is for people who want to build on FreeMoCap itself, not just use it. Start at the track overview.

## Science​

This track covers research applications. Measurement principles, data analysis workflows, biomechanics, and the neuroscience of movement all fall under it. This track is for researchers and clinicians who need to know what the data actually supports, not just how to produce it. Start at the track overview.

## Art​

This track covers creative applications. Cleaning up motion capture data for character animation, and getting it into game engines for interactive work, both fall under it. This track is for animators and game developers. Start at the track overview.

## Where this content lives​

Every link on this page points to the Skelly University curriculum repository on GitHub, not to a page on this site. The tracks are part of Skelly University, a planned course built from that same curriculum.
