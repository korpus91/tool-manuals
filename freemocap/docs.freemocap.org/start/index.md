# Get started with FreeMoCap

FreeMoCap turns ordinary webcams into a 3D motion capture system. Four steps take you from nothing installed to a skeleton moving on your screen.

- Install FreeMoCap.

- Make your first recording with one camera, to check that everything works.

- See what you made.

- Decide where to go next: more cameras, better calibration, analyzing your data, or Blender.

Stuck? See fix an installation problem or fix a calibration problem, or ask in #help-requests on Discord.
