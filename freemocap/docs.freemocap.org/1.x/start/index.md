# Get started with FreeMoCap

FreeMoCap turns ordinary webcams into a 3D motion capture rig. This page is the short version: four steps, no branching, from nothing installed to a skeleton moving on your screen.

- Install FreeMoCap, either with pip or with the packaged installer for your OS.

- Make your first recording, one camera, a few minutes, so you can confirm the whole pipeline works before adding more cameras.

- See what you made, find the output files and confirm the recording tracked cleanly.

- Where to go next, once you have a working recording, decide whether you need multiple cameras, better calibration, or want to go straight to analyzing the data or bringing it into Blender.

If you already know your way around Python environments and just want the commands, the short version is at the top of the install page. If you get stuck anywhere in this path, installation troubleshooting and calibration troubleshooting cover the most common problems, and the Discord #help-requests channel covers everything else.
